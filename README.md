# Damadama

Damadama is a habit journal. The proposed stack is ASP.NET Core, Vue with TypeScript, and PostgreSQL. The current work is planning and review. Coding still requires approval.

- [User stories and working guide](docs/project-management.md) links the GitHub backlog and explains how we work on a story.
- [Requirements](docs/requirements.md) describes the product behavior and constraints.
- [System design](docs/design.md) explains the proposed structure and how browser requests reach the database.
- [Domain glossary](docs/glossary.md) defines the terms used throughout the project.
