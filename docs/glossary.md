# Damadama domain glossary

Damadama is a habit journal. These terms have the same meaning throughout the project's requirements and design.

| Term | Meaning |
| --- | --- |
| Account | The identity that owns a person's habits, schedules, and entries. |
| Habit | A named practice with Good, Better, and Best definitions and its own recurring schedule. |
| Tier definition | A person's description of what Good, Better, or Best means for a habit. |
| Schedule | A habit's calendar-based repeat rule that determines its scheduled dates. |
| Schedule history | The preserved rules that determine which dates a habit was scheduled on in the past. |
| Scheduled date | A calendar date on which a habit is scheduled under the rule that applies to that date. |
| Calendar date | The fixed date of an entry, separate from the time of its edit. |
| Today | The current calendar date in the device's current timezone. |
| Daily entry | A recorded Good, Better, Best, or Rest selection for one habit on one scheduled date. |
| Result | The Good, Better, Best, or Rest selection recorded in an entry. |
| Rest | A recorded Rest result. A missing entry is not a Rest entry. |
| Missed date | A past scheduled date with no daily entry. |
| Edit time | The timestamp of an entry change, separate from its calendar date and the time a retry reaches the server. |
| Pending entry change | An entry change stored on the device whose server result is still unconfirmed. |
| Combined heatmap | A year view of points earned across the habits scheduled on each date. |
| Daily maximum | Three times the number of habits scheduled on a date, including habits with Rest entries. |

Use "daily entry" for a recorded selection. Avoid "task" and "todo". Use "Rest" for that result, and avoid "Skip".
