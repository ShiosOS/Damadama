# Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/ShiosOS/Damadama/security/advisories/new) to report a suspected vulnerability. Include the affected version or commit, steps to reproduce, the impact, and any suggested fix. Share exploit details through the private report instead of a public issue.

This repository checks dependency changes and scans source code as described in the [security controls guide](.github/security/README.md). A passing scan does not prove that a change is free of vulnerabilities.
